# CoBrowser для Android

Смотрите любые сайты вместе: общая комната по коду, выбор сервиса (YouTube, Google, Netflix, Disney+, RuTube, VK Видео, Избранное),
синхронные пауза / плей / перемотка видео, общий чат.

## Как получить APK (бесплатно, через GitHub)
1. Создай на GitHub новый репозиторий (можно приватный).
2. Загрузи в него ВСЁ содержимое этой папки, включая скрытую папку `.github`
   (проще всего с компьютера: Add file → Upload files, перетащить файлы и папки).
3. Открой вкладку **Actions** → «Build APK» → дождись зелёной галочки (5–10 минут).
   Если запуск не начался сам — нажми **Run workflow**.
4. Скачай APK: репозиторий → **Releases** → `latest` → `CoBrowser.apk`
   (или Actions → запуск → Artifacts).
5. Поставь APK на телефон (разреши установку из неизвестных источников).

Если сборка упала красным — открой лог упавшего шага и пришли мне текст ошибки.

## Как пользоваться
- Один создаёт комнату и делится кодом (кнопка ↗). Остальные вводят код.
- Хост выбирает сервис или вводит ссылку/поиск — у всех открывается то же самое.
- Гость может позвать всех на свою страницу кнопкой 📍.
- ⌂ — вернуться к выбору сервиса, ☆ — в избранное, 💬 — чат.
